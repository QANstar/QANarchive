## ADDED Requirements

### Requirement: 作品类型(2D / 3D)

系统 SHALL 允许用户在创建/编辑作品时选择类型(2D / 3D),默认 2D;3D 作品不需要 prompt 与 ComfyUI 工作流 JSON,画廊依据类型展示「3D」徽标与筛选。2D 作品不能添加 3D 资源。

#### Scenario: 创建3D作品无需prompt

- **WHEN** 用户新建作品时选择 3D 类型且不填写 prompt
- **THEN** 系统成功创建该 3D 作品,prompt 为空,详情页不要求展示 prompt

#### Scenario: 创建2D作品需prompt

- **WHEN** 用户新建作品时选择 2D 类型但未填写 prompt
- **THEN** 系统拒绝并返回 400 错误

#### Scenario: 2D作品被拒添加3D资源

- **WHEN** 用户向一个 2D 类型作品上传 3D 资源
- **THEN** 系统拒绝并返回 400 错误

#### Scenario: 含3D资源的作品改为2D被拒

- **WHEN** 用户把已含 3D 资源的作品(编辑时)类型改为 2D
- **THEN** 系统拒绝并返回 400 错误,提示先删除 3D 资源

#### Scenario: 3D作品卡片标记

- **WHEN** 用户查看一个 3D 类型作品
- **THEN** 画廊卡片显示「3D」徽标,画廊「3D」筛选只返回 3D 类型作品

### Requirement: 作品关联3D资源

系统 SHALL 允许 3D 类型作品关联 0..N 个 3D 资源(assets),每个资源为一个 fbx / blender(.blend) / 压缩包(zip)源文件;资源独立于图片/视频媒体,可排序、可增删。

#### Scenario: 为3D作品添加3D资源

- **WHEN** 用户为 3D 作品上传一个 3D 源文件
- **THEN** 系统保存该资源,作品详情页「3D 资源」区块展示该资源的原始文件名与对应类型

#### Scenario: 删除单个3D资源

- **WHEN** 用户删除作品的某个 3D 资源
- **THEN** 系统移除该资源的源文件,其余资源保留

#### Scenario: 调整3D资源顺序

- **WHEN** 用户调整作品 3D 资源的顺序并提交
- **THEN** 系统按新顺序展示资源

### Requirement: 统一缩略图(封面裁剪)

系统 SHALL 为作品提供统一的缩略图(即封面),2D/3D 共用一套配置;缩略图在选图后经裁剪(`ImageCropper`)生成,默认取第一张图片,也可手动上传图片并裁剪。

#### Scenario: 从图片设为封面并裁剪

- **WHEN** 用户在作品中某张图片上点击「设为封面」
- **THEN** 打开裁剪,确认后系统把裁剪结果存为该作品缩略图

#### Scenario: 手动上传并裁剪封面

- **WHEN** 用户上传一张图片作为封面
- **THEN** 系统打开裁剪,确认后保存裁剪结果为缩略图

#### Scenario: 封面回退

- **WHEN** 作品未显式设置缩略图
- **THEN** 卡片与列表使用第一张图片作为封面;无图片时使用占位符

### Requirement: 3D作品封面取图片

系统 SHALL 在一 3D 作品的封面/缩略图使用其图片媒体或手动裁剪结果,而不依赖 3D 资源的独立预览图。

#### Scenario: 3D作品无独立预览图

- **WHEN** 用户查看含图片的 3D 作品
- **THEN** 封面使用该图片媒体/裁剪结果,3D 资源不再单独上传预览图
