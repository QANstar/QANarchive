## ADDED Requirements

### Requirement: 作品关联3D资源

系统 SHALL 允许作品关联 0..N 个 3D 资源(assets),每个资源为一个 fbx / blender(.blend) / 压缩包(zip)源文件并配对一张预览图;资源独立于图片/视频媒体,可排序、可增删。

#### Scenario: 为作品添加3D资源

- **WHEN** 用户为作品上传一个 3D 源文件并配对其预览图
- **THEN** 系统保存该资源,作品详情页「3D 资源」区块展示该资源的预览图与对应类型

#### Scenario: 删除单个3D资源

- **WHEN** 用户删除作品的某个 3D 资源
- **THEN** 系统移除该资源的源文件与预览图文件,其余资源保留

#### Scenario: 调整3D资源顺序

- **WHEN** 用户调整作品 3D 资源的顺序并提交
- **THEN** 系统按新顺序展示资源

### Requirement: 3D资源预览图

系统 SHALL 要求作品每个 3D 资源配一张预览图,用于卡片与列表缩略图;预览图缺失时前端以降级占位符展示。

#### Scenario: 为3D资源上传预览图

- **WHEN** 用户上传 3D 资源时同时提供预览图
- **THEN** 系统保存预览图,作品卡片与详情页资源区块使用该预览图

### Requirement: 纯3D作品封面回退

系统 SHALL 在作品无显式封面且无图片媒体时,将默认封面回退为第一个 3D 资源的预览图。

#### Scenario: 纯3D作品展示封面

- **WHEN** 作品仅包含 3D 资源、不含图片媒体且未设置显式封面
- **THEN** 画廊卡片与列表使用第一个 3D 资源的预览图作为封面
