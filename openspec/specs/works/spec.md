## ADDED Requirements

### Requirement: 创建作品

系统 SHALL 允许已登录用户创建作品,作品包含标题、prompt、简介、标签,以及可选的工作流 JSON;创建后作品可在画廊中浏览。

#### Scenario: 创建含全部字段的作品

- **WHEN** 已登录用户提交作品表单,包含标题、prompt、简介、标签
- **THEN** 系统创建作品并返回其 ID,作品出现在画廊中

#### Scenario: 创建带工作流 JSON 的作品

- **WHEN** 用户提交作品时附带 ComfyUI 工作流 JSON(≤ 1MB)
- **THEN** 系统保存该 JSON,作品详情页可查看与下载

#### Scenario: 工作流 JSON 超限被拒

- **WHEN** 用户提交超过 1MB 的工作流 JSON
- **THEN** 系统拒绝保存并返回 400 错误

#### Scenario: 未登录创建作品被拒

- **WHEN** 未登录用户提交创建作品请求
- **THEN** 系统返回 401 未授权错误

### Requirement: 编辑作品

系统 SHALL 允许已登录用户编辑既有作品的标题、prompt、简介、标签与工作流 JSON;编辑后画廊与详情页反映最新内容。

#### Scenario: 编辑作品字段

- **WHEN** 用户修改作品的标题与 prompt 并提交
- **THEN** 系统更新作品,详情页展示新内容

#### Scenario: 清空工作流 JSON

- **WHEN** 用户删除作品的工作流 JSON 并提交
- **THEN** 系统将工作流 JSON 置空,详情页不再显示该内容

### Requirement: 删除作品

系统 SHALL 允许已登录用户删除作品;删除时同时清理其媒体文件、封面及所有关联关系(角色/部件/标签)。

#### Scenario: 删除作品

- **WHEN** 用户删除一个作品
- **THEN** 系统删除作品及其媒体文件、关联记录,作品从画廊消失

### Requirement: 作品关联角色(多对多)

系统 SHALL 允许一个作品关联 0..N 个角色,一个角色也可包含 0..N 个作品;不关联任何角色的作品即为「直接传图」。关联关系可增删。

#### Scenario: 作品关联多个角色

- **WHEN** 用户在创建/编辑作品时勾选多个角色并提交
- **THEN** 系统建立作品与这些角色的多对多关联,各角色合集页均展示该作品

#### Scenario: 作品不关联任何角色(直接传图)

- **WHEN** 用户创建作品时不勾选任何角色
- **THEN** 该作品作为独立作品存在,不出现于任何角色合集页

#### Scenario: 解除作品与角色的关联

- **WHEN** 用户编辑作品并取消勾选某个角色
- **THEN** 系统移除该关联,作品从该角色合集页消失

### Requirement: 作品关联部件(可选)

系统 SHALL 允许作品可选关联 0..N 个部件,用于追溯作品使用过的提示词部件;关联关系可增删,不关联也不影响作品功能。

#### Scenario: 为作品添加部件关联

- **WHEN** 用户在作品详情/编辑页为作品关联若干部件
- **THEN** 系统记录关联,作品详情页展示「用到的部件」区块

#### Scenario: 移除作品部件关联

- **WHEN** 用户移除作品与某部件的关联
- **THEN** 系统删除该关联,作品详情页不再展示该部件

### Requirement: 作品详情

系统 SHALL 提供作品详情视图,包含完整 prompt、工作流 JSON(可复制/下载)、媒体列表、简介、标签、关联角色与关联部件。

#### Scenario: 查看作品详情

- **WHEN** 用户打开某个作品的详情页
- **THEN** 页面展示作品的完整信息,包括全部媒体、prompt、工作流 JSON、关联角色与部件
